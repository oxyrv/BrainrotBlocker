# BrainrotBlocker
A simple userscript to block Brainrot related content in most websites ^^

## Disclaimer
There is a few websites that might be wrongly deleted due to it containing the word "brainrot", this being said, it NEVER deletes the whole page, only at the very maximum 6 containers above the mainly targeted content, this repo WILL be broken due to the script detecting the word in the desc/title.

## How to install
You can use any userscript manager extension, I personally recommend ViolentMonkey or TamperMonkey but any will do the job!

Simply add the script to your manager and there it is!
